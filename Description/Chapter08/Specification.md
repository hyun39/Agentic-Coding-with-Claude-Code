# Chapter 08: Creating and Customizing Output Styles

## 📌 개요
이 챕터는 에이전트의 응답을 단순히 텍스트로 받는 단계를 넘어, 프로젝트의 성격이나 사용자의 선호에 맞춰 **출력 형식(Output Style)을 커스터마이징**하는 고급 기법을 다룹니다. 응답을 HTML로 변환하여 브라우저에서 시각화하거나, 기계가 읽기 쉬운 구조화된 데이터(YAML 등)로 강제하는 '포맷터 에이전트'의 활용법을 실습합니다.

## 🌳 디렉토리 구조
```text
Chapter08/
├── .claude/
│   └── output-styles/              # 커스텀 출력 스타일 정의 저장소
│       ├── retro-ascii-blog.md     # 아스키 아트 스타일의 HTML 블로그 포맷터
│       └── yaml-concise.md         # 간결한 YAML 형식 포맷터
├── statusline.py                   # 대화 이력을 분석하여 상태창을 출력하는 헬퍼 스크립트
├── output-styles-guide.html        # 출력 스타일 활용 가이드 (문서)
└── output-styles-quick-guide.html  # 출력 스타일 퀵 가이드 (문서)
```

## ⚙️ 파일별 역할 및 부재 시 영향 (Impact Analysis)

| 파일/폴더명 | 역할 | 삭제/부재 시 발생하는 현상 |
| :--- | :--- | :--- |
| **`.claude/output-styles/`** | 출력의 스타일과 워크플로우를 결정하는 지침 파일들의 저장소 | 에이전트가 기본 텍스트 응답 방식만 사용하게 되어, 시각화나 데이터 구조화와 같은 향상된 UX를 제공할 수 없습니다. |
| **`retro-ascii-blog.md`** | 응답을 HTML 블로그 형태로 변환하고 브라우저로 여는 자동화 명세 | 에이전트가 응답을 HTML 파일로 저장하거나 아스키 아트를 활용한 레이아웃을 구성하지 못하며, 일반적인 마크다운 응답만 내놓습니다. |
| **`statusline.py`** | `transcript.jsonl`을 분석하여 현재 작업 상태(마지막 질문 등)를 터미널에 요약 출력 | 사용자가 대화의 누적 맥락을 파악하기 어려워지며, 특히 긴 작업 시 현재 에이전트가 어떤 지점을 수행 중인지 시각적으로 확인할 수 없습니다. |

## 💡 핵심 학습 개념

### 1. 포맷터 에이전트 (Formatter Agents)
- 출력 스타일 파일은 사실상 "출력 형식화 임무"를 띤 특수 목적 서브에이전트입니다.
- 단순한 '형식 지정'을 넘어, "파일로 저장하고 브라우저를 띄워라"와 같은 **후속 작업(Post-processing)** 절차를 포함할 수 있습니다.

### 2. 세션 트랜스크립트 분석 (Transcript Analysis)
- `statusline.py` 예제는 Claude Code 세션 중에 기록된 JSON 형태의 대화 로그를 실시간으로 분석하여 메타데이터(마지막 질문, 현재 스타일 등)를 추출하는 방법을 보여줍니다.
- 이를 통해 개발자는 에이전트의 현재 작업 상태를 대화창 밖에서도 모니터링할 수 있는 맞춤형 대시보드를 구축할 수 있습니다.

## 🚀 실습 절차
1. **스타일 정의**: `.claude/output-styles/` 하위에 전문화된 명령 세트를 작성합니다.
2. **스타일 전환**: Claude Code 내에서 명명된 스타일을 호출하여 응답이 HTML이나 YAML로 변하는지 확인합니다.
3. **상태 모니터링**: 별도의 터미널 창에서 `statusline.py`를 실행하여 현재 대화의 맥락이 실시간으로 요약되는지 테스트합니다.

## ✅ 결론 및 권장 사항
- **사용자 경험의 확장**: 단순히 정보를 얻는 것을 넘어, 정보를 '소비하는 방식'까지 에이전트가 제어하게 함으로써 개발 생산성을 높일 수 있습니다.
- **데이터 중심의 추적**: 세션 로그 파일(`transcript`)을 파이썬 스크립트와 연동하는 기법은 복잡한 다중 에이전트 환경에서 상태를 추적하는 가장 강력한 방법 중 하나입니다.
