# Chapter 04: Extending Claude Code with MCP Servers and Plugins

## 📌 개요
이 챕터는 Claude Code의 기본 지능을 넘어, 외부 지식 베이스나 전용 도구 세트에 접근할 수 있도록 하는 **MCP(Model Context Protocol)** 서버의 연동 방법을 다룹니다. 특히 원격 HTTP 서버를 도구로 등록하고, 특정 상황에서 에이전트가 이를 우선적으로 활용하도록 지시하는 '컨텍스트 기반 도구 선택' 전략을 실습합니다.

## 🌳 디렉토리 구조
```text
Chapter04/
├── .mcp.json               # 외부 MCP 서버(context7) 연동 설정 파일
└── CLAUDE.md               # 특정 도메인 작업 시 MCP 도구 활용 지침
```

## ⚙️ 파일별 역할 및 부재 시 영향 (Impact Analysis)

| 파일/폴더명 | 역할 | 삭제/부재 시 발생하는 현상 |
| :--- | :--- | :--- |
| **`.mcp.json`** | 외부 MCP 서버(`context7`)의 URL 및 연결 유형 정의 | 에이전트가 외부 도구에 연결할 수 없으며, 로컬에 없는 지식이나 특수 기능을 수행할 수 없게 됩니다. |
| **`CLAUDE.md`** | 특정 주제(LangGraph 등)에서 MCP 서버를 사용하도록 명령 | MCP 서버가 연결되어 있더라도 에이전트가 언제 해당 도구를 꺼내 써야 할지 판단하지 못해 일반적인 추론(Hallucination 위험)에 의존하게 됩니다. |

## 💡 핵심 학습 개념

### 1. 원격 MCP 서버 연동 (HTTP-based MCP)
- 로컬 스크립트가 아닌, 표준화된 인터페이스(HTTP/SSE 등)를 통해 외부에 구축된 전문 도구 세트를 활용합니다.
- `mcpServers` 설정을 통해 서버 이름과 엔드포인트를 등록하면 Claude Code의 도구 상자에 즉시 추가됩니다.

### 2. 도메인 특화 도구 라우팅 (Tool Routing)
- `CLAUDE.md`를 활용해 에이전트의 판단 로직을 보완합니다.
- **예**: "LangGraph 관련 질문이면 `context7` 도구를 사용해라"와 같이 작업의 문맥에 따라 최적의 외부 도구를 강제로 연결시켜 정확도를 높입니다.

## 🚀 실습 절차
1. **MCP 설정 등록**: `.mcp.json`에 원격 서버 URL을 기입합니다.
2. **지침 주입**: `CLAUDE.md`에 특정 키워드(예: LangGraph)와 도구 사용의 연관성을 명시합니다.
3. **지식 확장 확인**: 에이전트에게 관련 질문을 던져, 스스로 외부 MCP 도구를 실행하여 정보를 가져오는지 확인합니다.

## ✅ 결론 및 권장 사항
- **최신성 유지**: 에이전트의 내부 지식(훈련 데이터)만으로는 해결할 수 없는 최신 기술 트렌드 정보는 반드시 외부 MCP를 통해 보충해야 합니다.
- **지시사항의 구체화**: 단순한 도구 등록보다 "언제 이 도구를 써야 하는가"를 `CLAUDE.md`에 명시하는 것이 실질적인 에이전트 성능 향상의 핵심입니다.
