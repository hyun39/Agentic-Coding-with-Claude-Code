# Chapter 03: Getting Started with Claude Code – A Tour of Essential Commands

## 📌 개요
이 챕터는 Claude Code의 기본 기능을 넘어, 사용자의 생산성을 높이기 위해 도구를 **커스터마이징**하고 **확장**하는 방법을 다룹니다. 슬래시 명령어를 직접 정의하여 복잡한 작업을 단축어로 실행하고, 훅(Hooks) 시스템을 이용해 에이전트의 작업 완료 시 알림을 받는 등의 고급 워크플로우를 실습합니다.

## 🌳 디렉토리 구조
```text
Chapter03/
├── custom commands/            # 커스텀 슬래시 명령어 실습 폴더
│   └── .claude/
│       └── commands/           # 명령어 정의 파일 저장소
│           ├── commit-code.md  # /commit-code 명령어 정의
│           └── dad-joke.md     # /dad-joke 명령어 정의
└── hooks-notification/         # 이벤트 훅 및 알림 실습 폴더
    ├── .claude/
    │   └── settings.json       # 훅 트리거 및 실행 경로 설정
    ├── play_sound.py           # 알림 사운드를 재생하는 Python 스크립트
    ├── ulala.wav               # 알림용 오디오 파일
    ├── pyproject.toml          # 의존성 관리 (uv run용)
    └── README.md               # 훅 시스템 설정 가이드
```

## ⚙️ 파일별 역할 및 부재 시 영향 (Impact Analysis)

| 파일/폴더명 | 역할 | 삭제/부재 시 발생하는 현상 |
| :--- | :--- | :--- |
| **`.claude/commands/`** | 새로운 슬래시 명령어를 추가하기 위한 마크다운 파일들의 저장소 | 커스텀 명령어 기능 자체가 대화창에 나타나지 않으며, 반복적인 작업을 자동화할 수 없습니다. |
| **`.claude/settings.json`** | 에이전트의 라이프사이클 이벤트(Stop, Start 등)와 실행할 명령어를 매핑 | 훅 시스템의 '두뇌'가 사라지는 것으로, 에이전트가 작업을 마쳐도 외부 스크립트(알림 등)가 트리거되지 않습니다. |
| **`play_sound.py`** | 훅에 의해 실행되는 구체적인 동작(오디오 재생) 구현체 | 훅은 정상적으로 트리거되지만, 실제 실행 시 스크립트를 찾지 못해 오류가 발생하거나 알림이 실종됩니다. |
| **`commit-code.md`** | 커밋 메시지 생성 및 스테이징 명령을 단축한 스펙 | 사용자가 `/commit-code`를 입력해도 Claude가 해당 명령의 존재를 인지하지 못합니다. |

## 💡 핵심 학습 개념

### 1. 커스텀 슬래시 명령어 (Custom Slash Commands)
- `.claude/commands/` 하위에 마크다운 파일을 생성하여 정의합니다.
- 파일 내의 지침(Instructions)은 해당 명령어가 입력될 때 에이전트에게 주입되는 추가 프롬프트 역할을 합니다.
- **예**: `/commit-code` -> "변경된 파일을 스테이징하고 컨벤션에 맞는 메시지로 커밋해줘"라는 긴 지시를 대체합니다.

### 2. 이벤트 훅 (Life Cycle Hooks)
- 에이전트의 특정 상태 변화에 반응하여 셸 명령어를 실행합니다.
- `Stop` 이벤트: 에이전트가 모든 작업을 완료하고 사용자 응답을 기다리는 시점에 발생합니다.
- 장시간 진행되는 작업 시, 완료 여부를 사운드나 알림으로 확인하여 멀티태스킹 효율을 높일 수 있습니다.

## 🚀 실습 절차
1. **커스텀 명령 실행**: `.claude/commands` 폴더 내에 명세 파일을 만들고 Claude Code에서 `/`를 눌러 명령어가 활성화되는지 확인합니다.
2. **훅 설정**: `settings.json`에 이벤트 종류와 실행할 스크립트 절대 경로를 기입합니다.
3. **알림 테스트**: 복잡한 작업을 지시한 후, 에이전트가 완료했을 때 `play_sound.py`가 정상 작동하는지 확인합니다.

## ✅ 결론 및 권장 사항
- **절대 경로 사용**: `settings.json`에서 명령을 설정할 때는 시스템 어디서나 실행 가능하도록 파일의 **절대 경로**를 사용하는 것이 안전합니다.
- **반복의 최소화**: 자주 사용하는 복잡한 프롬프트는 반드시 커스텀 명령어로 등록하여 컨텍스트 윈도우를 효율적으로 관리하십시오.
