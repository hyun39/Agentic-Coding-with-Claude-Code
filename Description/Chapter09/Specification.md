# Chapter 09: Understanding Agent Skills

## 📌 개요
이 챕터는 Claude Code의 능력을 실질적으로 확장하는 핵심 단위인 **에이전트 스킬(Agent Skills)**을 다룹니다. 단순한 프롬프트 지시를 넘어, 에이전트가 특정 상황에서 스스로 복잡한 외부 스크립트를 실행하고, 그 실행 결과와 AI의 추론을 결합하여 고도로 자동화된 '에이전틱 워크플로우'를 구축하는 방법을 실습합니다.

## 🌳 디렉토리 구조
```text
Chapter09/
└── .claude/
    └── skills/                     # 프로젝트 전용 스킬 저장소
        └── git-pushing/            # Git 작업 자동화 스킬 폴더
            ├── SKILL.MD            # 스킬의 목적, 사용 시점, 실행 지침 정의
            └── scripts/            # 실제 실행되는 로직(스크립트) 폴더
                └── smart_commit.sh # 스마트 커밋 및 푸시 자동화 스크립트
```

## ⚙️ 파일별 역할 및 부재 시 영향 (Impact Analysis)

| 파일/폴더명 | 역할 | 삭제/부재 시 발생하는 현상 |
| :--- | :--- | :--- |
| **`SKILL.MD`** | 스킬의 이름, 트리거 키워드(push, commit 등), 실행할 명령어 명세 | 에이전트가 해당 자동화 기능의 존재를 인지하지 못하며, 사용자가 요청해도 내장된 일반 도구(Bash 등)를 사용하여 비효율적으로 작업하게 됩니다. |
| **`smart_commit.sh`** | 스테이징, AI 기반 커밋 메시지 생성, 푸시 로직이 담긴 실행 파일 | 에이전트가 스킬 사용을 시도하더라도 실제 실행할 로직이 없어 에러가 발생하거나, 워크플로우를 완료하지 못하고 중단됩니다. |
| **`.claude/skills/`** | 커스텀 능력을 체계적으로 관리하는 최상위 디렉토리 | 프로젝트에 특화된 모든 고단위 자동화 기능이 비활성화되어, 에이전트가 일반적인 코딩 보조 도구 수준으로 지능이 제한됩니다. |

## 💡 핵심 학습 개념

### 1. 스킬 트리거 (Skill Triggering)
- `SKILL.MD`의 Frontmatter에 기술된 `description`을 통해 에이전트가 "지금이 이 스킬을 쓸 때인가?"를 판단합니다.
- 특정 단어나 의도(예: "push changes", "save to remote")가 감지되면 해당 워크플로우가 활성화됩니다.

### 2. 결정론적 도구와 AI 추론의 결합
- **`smart_commit.sh`** 사례처럼, 안정적인 셸 스크립트 내부에 **Claude CLI(`claude -p`)**를 호출하여 창의적인 작업(커밋 메시지 생성)을 수행합니다.
- 이는 자동화의 안정성과 AI의 유연성을 동시에 확보하는 **하이브리드 자동화** 모델입니다.

### 3. 점진적 로딩 (Progressive Loading)
- 모든 지침을 메인 컨텍스트에 담지 않고, 스킬 파일에 분리하여 저장합니다.
- 에이전트가 필요할 때만 해당 명세를 읽어오므로 전체 컨텍스트 창을 효율적으로 관리할 수 있습니다.

## 🚀 실습 절차
1. **스킬 명세 작성**: `SKILL.MD`를 통해 에이전트에게 "언제 스크립트를 써야 하는지" 가르칩니다.
2. **스크립트 구현**: 복잡한 비즈니스 로직(예: 컨벤션 체크, 푸시 전략)을 `scripts/` 내 파일로 작성합니다.
3. **워크플로우 테스트**: "작업 다 끝났어, 서버에 올려줘"라고 모호하게 요청해도 에이전트가 스스로 `git-pushing` 스킬을 꺼내 쓰는지 확인합니다.

## ✅ 결론 및 권장 사항
- **스크립트 위임의 원칙**: 에이전트가 직접 터미널에 한 줄씩 명령어를 치게 하지 말고, 검증된 하나의 큰 스크립트를 실행하게 유도하는 것이 더 견고한 자동화를 만듭니다.
- **AI-Native Scripts**: 스크립트 작성 시 데이터 가공이나 판단이 필요한 부분은 과감히 내부에서 Claude CLI를 호출하여 처리하도록 설계하십시오.
